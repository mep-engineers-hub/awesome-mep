# Contributing to awesome-mep

> **Unverified. Not for stamped or issued work. Check against the adopted code edition.**

The organization-wide rules in the [.github CONTRIBUTING](https://github.com/mep-engineers-hub/.github/blob/main/CONTRIBUTING.md) apply. In addition:

## Add a tool

1. Check that it is not already listed.
2. Copy [ENTRY_TEMPLATE.md](ENTRY_TEMPLATE.md) to `entries/<tool-name>.md` and fill it in.
3. Add one row to the right section of [README.md](README.md), alphabetical order.
4. Set the tier honestly (see [TIERS.md](TIERS.md)). Without test evidence, it is **Found**.
5. Flag the license: ⚠ for GPL/AGPL, ⛔ for no license.
6. Open a pull request. One member reviews; the maintainer merges.

## Promote a tier

Open a PR that updates the entry file with your evidence and the README row. The reviewer checks that the evidence meets [TIERS.md](TIERS.md).

## Not accepted

- Tools that need copyrighted standard tables bundled to work, unless the user supplies them.
- Entries copied from other directories without a check of the link and license.
- Paid tools listed as an advert. Paid tools may be listed with a clear "commercial" note if a member has tried them.
- Your own tool without a disclosure line ("Author: me").
